# Case

Generated by `build.py` (manifold3d + trimesh, STEP via cadquery-ocp). STL and STEP files land in `out/`; STEP is for services that don't take STL (PCBWay 3D printing).

| File | Print | Notes |
|------|-------|-------|
| `test_frame.stl` | first! ~30 min | Front 5 mm only: check window, LED windows and look |
| `case_front.stl` | face down, no supports | 0.2 mm layers, 3 walls, 20 % infill (the LED window plate bridges over the diffuser recess) |
| `case_back.stl` | flat side down, no supports | press a 1/4"-20 nut into the hex pocket from inside |
| `diffuser_top.stl`, `diffuser_side.stl` (×2) | flat | white or natural PETG, 100 % infill; glue flush into the recesses on the front |

Material: PETG or ASA (PLA softens in a warm room or sun). Black looks best;
the reference photos use blue with carbon texture.

Hardware: 4× M3 heat-set inserts (4.0 mm hole, ≤ 8 mm long), 4× M3×8 screws,
1× 1/4"-20 hex nut.

**Before printing the full case:** the display dimensions in `build.py` are
not measured yet. When the board arrives, measure `MODULE_W/H/T`, the active
area position and the USB-C position, edit the constants and run
`python3 hardware/case/build.py` again.
